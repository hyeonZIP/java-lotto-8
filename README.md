# 로또 발매기

## 0️⃣ 공통 규칙

- 모든 입력에 대한 예외가 발생한 경우 재입력
- 모든 예외에 대한 에러 문구 `[ERROR]`로 시작
  ```
  [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
  ```

## 1️⃣ 로또 구입 금액 입력

- [x] 구입금액 입력 가이드문 출력 : `구입금액을 입력해 주세요.`
- [x] 구입금액 입력 : `8000`
    - [x] 구입금액 입력
    - [x] _공백을 입력하는 경우 예외 처리_
    - [x] _정수가 아닐 경우 예외 처리_
    - [x] _양수가 아닐 경우 예외 처리_
    - [x] _구매 금액이 1억을 넘을 경우 예외 처리_
    - [x] _`로또 1장의 가격(1,000)`으로 나누어 떨어지지 않는 경우 예외 처리_

## 2️⃣ 로또 구매

- [x] `구입금액 / 로또 1장의 가격(1,000)`만큼 로또 발행
    - [x] `구입금액 / 로또 1장의 가격(1,000)`만큼 로또 발행
    - [x] _하나의 로또에 뽑힌 숫자가 6개가 아닌 경우 예외 처리_
    - [x] _하나의 로또에 중복된 숫자가 있는 경우 예외 처리_
    - [x] _로또 번호의 숫자 범위를 벗어날 경우 예외 처리_
- [ ] 발행한 로또 수량 가이드문 출력 : `8개를 구매했습니다.`
- [ ] 발행한 로또 번호 출력
  > 💡로또 번호는 오름차순 정렬
  ```
  [8, 21, 23, 41, 42, 43] 
  [3, 5, 11, 16, 32, 38] 
  [7, 11, 16, 35, 36, 44] 
  [1, 8, 11, 31, 41, 42] 
  [13, 14, 16, 38, 42, 45] 
  [7, 11, 30, 40, 42, 43] 
  [2, 13, 22, 32, 38, 45] 
  [1, 3, 5, 14, 22, 45]
  ```

## 3️⃣ 당첨 번호 입력

- [ ] 당첨 번호 입력 가이드문 출력 : `당첨 번호를 입력해 주세요.`
- [ ] 당첨 번호 입력 : `1,2,3,4,5,6`
    - [ ] 당첨 번호 입력
    - [ ] _공백을 입력하는 경우 예외 처리_
    - [ ] `,`를 기준으로 당첨 번호 분리
    - [ ] _당첨 번호가 `6`개가 아닐 경우 예외 처리_
    - [ ] _정수가 아닐 경우 예외 처리_
    - [ ] _번호가 `1~45` 사이의 숫자가 아닐 시 예외 처리_
    - [ ] _중복된 당첨 번호가 있을 경우 예외 처리_

## 4️⃣ 보너스 번호 입력

- [ ] 보너스 번호 입력 가이드문 출력 : `보너스 번호를 입력해 주세요.`
- [ ] 보너스 번호 입력 : `7`
    - [ ] 당첨 번호 입력
    - [ ] _공백을 입력하는 경우 예외 처리_
    - [ ] _정수가 아닐 경우 예외 처리_
    - [ ] _번호가 `1~45` 사이의 숫자가 아닐 시 예외 처리_
    - [ ] _당첨 번호와 동일한 번호를 입력할 경우 예외 처리_

## 5️⃣ 로또 결과 집계

- [ ] 구매한 로또 번호별 당첨 등수 판정
    - [ ] 당첨 번호와 일치 개수 계산
    - [ ] 보너스 번호와 일치 여부 확인
    - [ ] 당첨 등수 판정
      ```
      1등: 6개 번호 일치 / 2,000,000,000원
      2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
      3등: 5개 번호 일치 / 1,500,000원
      4등: 4개 번호 일치 / 50,000원
      5등: 3개 번호 일치 / 5,000원
      ```
- [ ] 수익률 계산
  > 💡수익률은 소수점 둘째 자리에서 반올림

## 6️⃣ 당첨 통계 출력

- [ ] 당첨 통계 Header 출력 : `당첨 통계`
- [ ] 당첨 통계 Header 와 Body 간 구분자 출력 : `---`
- [ ] 당첨 통계 Body 출력(당첨 일치 갯수) :
  ```
  3개 일치 (5,000원) - 1개
  4개 일치 (50,000원) - 0개
  5개 일치 (1,500,000원) - 0개
  5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
  6개 일치 (2,000,000,000원) - 0개
  ```
- [ ] 당첨 통계 Footer 출력(수익률) : `총 수익률은 62.5%입니다.`
